# Altostrat Singapore — HR Policy Knowledge Bundle

Curated knowledge from the **Altostrat Singapore Employee Policy Handbook &
Conduct Guidelines** (Last Updated: July 2026), expressed in Google's Open
Knowledge Format (OKF v0.1).

Each concept file is **one policy area**. An agent answering a question should read
this index, choose the relevant concept, and read that file — deliberate
navigation, not semantic guessing. This bundle is curated (it covers the
most-queried policies), and is designed to be extended: add a concept by dropping
in a new markdown file with frontmatter.
